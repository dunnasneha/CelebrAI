About CelebrAI

"Plan Beautiful Moments, Effortlessly."

Built for PromptWars Challenge 5: Celebration & Event Planner. CelebrAI represents a complete, full-stack event intelligence platform powered by Python Flask, SQLite, and Google Gemini GenAI.

Technical Architecture:

  • Backend: Python 3 + Flask REST API
  • Persistence: SQLite (foreign keys, cascading delete, JSON storage)
  • GenAI Engine: Google Gemini API (gemini-1.5-flash) with structured schema
  • PDF Generation: ReportLab multi-page executive blueprint
  • Charts & UX: Chart.js, HTML5, CSS3 Custom System & Vanilla JavaScript
